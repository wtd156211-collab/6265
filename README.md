# 折线简化与误差上界（从 0 实现）

起始环境只有本说明、`samples/**` 与 `.gitignore`：引擎、页面、测试都从零写。运行时是 Python 3.13，只用标准库；
页面是原生 HTML/Canvas，无构建、无依赖；测试用 `unittest`，只读 `samples/**`。`samples/notes.md` 是现场记录，
不参与判定。

## 1. 范围

做的：读一条有序点列的轨迹与一个误差阈值，输出一条更短的折线（保留点取自输入点列）；保住端点与顺序；
库与命令行入口共用一份实现；把原轨迹与简化折线画成对比页面；`out/` 下只放运行期产物。

不做：地图底图与地理投影、坐标系换算、网络与 CDN、第三方库与构建步骤、三维与时间维度压缩、实时流式与增量简化、
多轨迹合并与批处理、页面上的编辑与参数调节。

## 2. 口径与公式

- **点列**：`P0 … P(n-1)` 是有序点列，平面直角坐标，单位米；相邻两点之间是直线段。
- **保留点**：输出是输入的子序列——保留点的下标严格递增，第 0 个与第 `n-1` 个点必须保留，不得新造点、
  不得改坐标、不得重排。
- **垂直距离**：点 `P`、它前后相邻的两个保留点 `A`（前）与 `B`（后），`u = B - A`，`t = ((P-A)·u)/(u·u)`：
  `t ≤ 0` 取 `|P-A|`，`t ≥ 1` 取 `|P-B|`，否则取 `|(P-A) × u| / |u|`（`×` 是二维叉积）。`A`、`B` 坐标相同时
  取 `|P-A|`。
- **误差口径（硬约束）**：每个被丢弃的点，到留下来的折线上覆盖它的那一段的垂直距离都必须 ≤ `eps`——覆盖它的
  那一段，就是输出里它前后相邻的两个保留点连成的弦；判定只看这一对点，扫一遍就够。
- **最大偏差**：所有被丢弃点的垂直距离的最大值（一个都没丢就是 0），页面与统计上报的就是它。
- **压缩比**：输出点数 ÷ 输入点数，写 6 位小数。
- **点数上限**：每条样例另有一个 `max_points`，输出点数必须 ≤ 它；误差与点数两个门槛要一起满足，破一条就不算过。
- **自交**：输出折线里两条不相邻的线段不许相交。共享端点不算，两端点坐标相同的零长度线段跳过；线段相交包括
  端点落在另一条线段上与共线重叠。
- **浮点**：坐标最多 3 位小数，判定用 `≤ eps + 1e-9` 的容差，双精度就够。
- **确定性**：同一输入、同一参数跑两遍，输出文件逐字节相同；不依赖系统时钟、随机数、哈希随机化
  （`PYTHONHASHSEED`）与字典、集合的遍历顺序。

## 3. 算法与数据结构（自选）

算法自选，复杂度与常数都不卡，只要两个硬约束都满足。三条提示：误差口径只管相邻保留点之间的那一段，可以从左往右
一格一格地扩张，不必两两比；`05-tail.txt` 有一百万点，别对每个点遍历全部保留线段；重复坐标、回折与原地打转都是
合法输入，不许先排序或去重。

## 4. 输入输出与文件格式

本节文件都是 UTF-8、单 `\n`、末行也有换行；数字是十进制，不带指数。

### 4.1 轨迹 `samples/tracks/<名>.txt`

每行一个点 `x y`（空白分隔），行号即点序；空行与 `#` 开头的注释行忽略；坐标可负，最多 3 位小数。

### 4.2 输出轨迹 `out/<名>.txt`

每行 `i x y`：`i` 是 0 起、在输入里的下标，严格递增；`x`、`y` 与输入中第 `i` 个点的坐标数值相同；首行
`i=0`，末行 `i=n-1`（按数值比较，容差 1e-9）。样例的期望结果见 `samples/expected/<名>.txt`。

### 4.3 命令行

仓库根目录执行，`engine.py` 既是库也是入口，诊断走 stderr：

```
python engine.py simplify <轨迹> <输出文件> --eps <阈值> --max-points <上限>
python engine.py page <轨迹> <输出文件> <页面文件>
```

`simplify` 按 4.2 写输出文件，并向 stdout 打一行统计
`STAT|in=<输入点数>|out=<输出点数>|eps=<阈值>|max_dev=<最大偏差>|ratio=<压缩比>`：`eps` 去掉多余的 0，
`max_dev` 与 `ratio` 各 6 位小数。退出码 0 表示写完输出，1 表示输入或参数不可用且不写输出。

### 4.4 页面 `web/`

`page` 在 `web/` 下写一个自包含 HTML（数据内联、不 `fetch`、不引 CDN、不起服务，双击即开）：① 原轨迹与简化折线画在同一
坐标系里，两种颜色、都看得见（叠画或左右并排都行），并带图例；② 输入点数、输出点数、压缩比、最大偏差四个数字；
③ 画出来的点列与写出来的数字都取自 4.1 与 4.3 的产物，页面里不重新简化、不自己换一套口径。跑两遍逐字节相同。

### 4.5 期望结果 `samples/expected/<名>.txt`

每条样例一份，`#` 开头是注释，判定只读下面几行（`|` 分隔，字段名固定）：

```
TRACK|samples/tracks/<名>.txt|points=<输入点数>
LIMIT|eps=<阈值>|max_points=<上限>
CHECK|out_rows|i_x_y|index_strictly_increasing=1|first=0|last=<末点下标>
CHECK|deviation|cover_chord|eps=<阈值>|tol=1e-9
CHECK|max_points|limit=<上限>
CHECK|crossing|self_intersection=none
CHECK|stats|max_dev_matches_checker|tol=1e-6
CHECK|determinism|simplify_runs=2|sha256_of_out|equal=1
CHECK|determinism|pythonhashseed=0,1,2|sha256_of_out|equal=1
CHECK|determinism|page_runs=2|sha256_of_page|equal=1
BASELINE|uniform-round|max_points=<上限>|max_dev=<值>|over_eps=<0|1>
```

`BASELINE` 是"同样点数、等间隔抽点"的对照：下标按 `i_k = (2k(n-1) + (m-1)) // (2(m-1))`（`k = 0…m-1`，
`m` 是上限）取，偏差按第 2 节口径算，`over_eps=1` 就是这条朴素做法破了误差约束。

## 5. 性能与验收口径

规模与预算（测试机 Windows + Python 3.13、单进程单线程）：`05-tail.txt` 一百万点，`simplify` ≤ 8 秒、
峰值内存 ≤ 512 MiB（`tracemalloc` 扣基线）；其余样例单条 ≤ 1 秒。页面生成不计入这两条。

逐条验收：

1. 环境：Python 3.13 + 标准库，无构建、无网络；运行期只在 `out/`、`var/` 下写，这两个目录不入库。
2. 形状：每条样例跑 `simplify`，输出按 4.2 的行格式、下标严格递增、首 0 末 `n-1`，输出折线不自交（第 2 节口径）。
3. 误差：按第 2 节口径算出的最大偏差 ≤ `eps + 1e-9`；`STAT` 里的 `max_dev` 与判定器相差 ≤ 1e-6。
4. 点数：输出点数 ≤ `LIMIT` 里的 `max_points`。
5. 确定性：连跑两遍、再换 `PYTHONHASHSEED` 跑一遍，输出文件 sha256 都相同；`page` 跑两遍逐字节相同。
6. 对照：`BASELINE` 行的值与判定器按 4.5 的规则算出来的一致。

上限不要求最优：`max_points` 按同阈值下可达点数留了约三成余量；`BASELINE` 行说明同样点数等间隔抽点会破误差
——点数得跟着曲率走，不然弯道就被削平了。

## 6. 样例说明

`samples/tracks/<名>.txt` 与 `samples/expected/<名>.txt` 一一对应，括号里是输入点数 / `eps`（米）/ 点数上限：

| 轨迹 | 场景与关键结果 |
| --- | --- |
| `01-arc.txt` | 平滑曲线（4000 / 0.4 / 111）：三段相切的圆弧，曲率逐段变化 |
| `02-drift.txt` | 抖动的实测数据（20000 / 1.5 / 49）：长直路段叠上 GPS 抖动，中间夹着两个野值 |
| `03-loop.txt` | 原地打转（6000 / 0.5 / 141）：同一个椭圆圈绕 8 圈，每圈往外扩 6% |
| `04-straight.txt` | 直线段（5000 / 1 / 2）：十公里直路，上限就是首尾两点 |
| `05-tail.txt` | 极端长尾（1000000 / 1 / 17）：绝大多数点停在原地，只有一小段急弯要留点 |
